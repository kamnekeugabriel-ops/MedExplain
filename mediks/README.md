# Mediks

Explique en termes simples les carnets médicaux, hors-ligne, avec Gemma et Ollama.
Licence : Apache 2.0.

## Lancer (étapes a, b et c)
1. Ollama doit tourner (`ollama serve`) avec un modèle installé.
2. `npm install` (une seule fois, avec internet)
3. `npm run dev`
4. Ouvrir l'adresse affichée (locale ou réseau).
